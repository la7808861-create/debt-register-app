# سجل الديون - تطبيق هاتف

تطبيق ويب موبايل PWA مستوحى من فكرة الصورة: إدارة العملاء، تسجيل الديون، تسجيل التسديد، البحث، التقارير، والنسخ الاحتياطي.

## التشغيل على الكمبيوتر

افتح `index.html` مباشرة في المتصفح.

## التشغيل على هاتف قريب

شغل خادمًا محليًا من داخل هذا المجلد:

```bash
python -m http.server 8080 --bind 0.0.0.0
```

ثم افتح من الهاتف عنوان الكمبيوتر على نفس شبكة الواي فاي.

## التشغيل على هاتف الزبون

ارفع ملفات هذا المجلد إلى أي استضافة مواقع ثابتة، ثم أعط الزبون الرابط. من متصفح الهاتف يمكنه اختيار "إضافة إلى الشاشة الرئيسية" ليظهر كتطبيق.
